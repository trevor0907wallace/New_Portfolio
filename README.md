# Sunny Hooda — Portfolio

Personal portfolio for **Sunny Hooda**, an IT Support & Security technician based in Oakville, Ontario.

Windows administration · Active Directory · Networking · Hands-on cybersecurity.

## Tech
- Single self-contained `index.html` (no build step)
- Vanilla HTML / CSS / JavaScript
- Google Fonts: Bricolage Grotesque, Plus Jakarta Sans, JetBrains Mono
- Light / dark theme, scroll-reveal animations, responsive down to phone width

## Deploy
Static site — deploys as-is on Vercel, Netlify, GitHub Pages, or any static host.
On Vercel: import the repo, framework preset **Other**, no build command, output = repo root.
